# Afterlife Judgment Portal

A web-based karmic evaluation and afterlife classification system developed using PHP and MySQL.

## Features

- Soul registration
- Karmic score calculation
- Afterlife classification
- Search records
- Statistics dashboard
- Input validation
- MySQL database integration

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Judgment Rules

| Score | Destination |
|---------|---------|
| >= 80 | Supreme Heaven |
| 40 - 79 | Heaven |
| 0 - 39 | Rebirth |
| < 0 | Hell |
